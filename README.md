# Fast_Food

**Fastfood – Sistema Web de Gestión Integral para Restaurantes.**

El proyecto busca centralizar en una única plataforma web todos los procesos operativos de un restaurante: la exhibición del menú, la toma de pedidos, la gestión de mesas y reservas, la comunicación con cocina, el control de inventario y la generación de reportes administrativos, de manera que la información fluya de forma ordenada entre cada área.

## Objetivo general
Desarrollar una plataforma web que centralice y digitalice los procesos operativos de un restaurante —menú, pedidos, reservas, cocina, inventario y administración— para optimizar la eficiencia interna y mejorar la experiencia de los clientes.

## Usuarios
| Rol | Qué hace |
|---|---|
| Cliente | Consulta el menú, hace pedidos y reservas, revisa su historial. |
| Cocina | Ve los pedidos entrantes y actualiza su estado. |
| Administrador | Gestiona menú, inventario, mesas, pedidos y reportes. |

## Cómo abrirlo
1. Clona el repositorio y abre la carpeta en VS Code.
2. Abre `sitio-web-empresa/index.html` con la extensión **Live Server**.

Usuarios de prueba (clave `1234`): `cliente@fastfood.com`, `cocina@fastfood.com`, `admin@fastfood.com`.

Ver más detalles en [`sitio-web-empresa/README.md`](sitio-web-empresa/README.md).
